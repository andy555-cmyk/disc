개인정보처리방침

이 사이트는 이름·이메일·연락처를 포함한 어떤 개인정보도 수집하지 않습니다. 검사 응답은 사용자의 브라우저 안에서만 계산되고 서버로 전송되지 않습니다. 아래는 그 사실과, 방문 통계·광고처럼 제3자 서비스가 관여하는 부분을 적은 것입니다.

2. 검사 응답 — 수집하지 않습니다

문항 선택, 채점, 유형 판정, 결과 리포트 생성은 전부 이 페이지에 포함된 자바스크립트가 사용자의 브라우저 안에서 처리합니다. 응답이나 결과를 서버로 보내는 코드가 없고, 회원가입·로그인이 없으며, 이름·나이·이메일 같은 정보를 묻지 않습니다. 페이지를 닫으면 결과도 함께 사라집니다.

3. 결과 코드와 공유 링크

결과 화면의 코드(예: DI-6622)와 「결과 링크 복사」로 만든 주소에는 유형 글자와 강도 등급 네 자리만 들어 있습니다. 개인을 식별할 수 있는 정보는 포함되지 않으며, 이 코드를 다른 사람에게 보낼지는 사용자가 직접 정합니다. 궁합·팀 분석에 입력한 상대의 코드 역시 브라우저 안에서만 비교되고 저장·전송되지 않습니다.

4. 방문 통계

사이트 개선을 위해 Cloudflare Web Analytics로 방문 수를 집계합니다. 이 도구는 쿠키를 쓰지 않고, 기기 식별자나 IP 주소로 개인을 추적하지 않으며, 방문한 페이지 주소·브라우저 종류·국가 수준의 집계 정보만 다룹니다. 자세한 내용은 Cloudflare Web Analytics 안내를 참고하세요.

5. 광고와 쿠키

이 사이트는 구글 애드센스 광고를 게재할 수 있습니다. 광고가 표시되는 경우, 구글을 포함한 제3자 광고 사업자는 사용자가 이 사이트와 다른 웹사이트를 방문한 기록을 바탕으로 광고를 보여 주기 위해 쿠키(광고 쿠키)를 사용할 수 있습니다. 이 쿠키는 운영자가 아니라 광고 사업자가 설정·관리하며, 운영자는 그 내용을 열람하지 못합니다.

  • 맞춤 광고 사용 중지: 구글 광고 설정
  • 구글의 광고 쿠키 사용 방식: 구글 정책 — 광고
  • 브라우저 설정에서 쿠키를 차단하거나 삭제할 수 있습니다. 차단해도 검사 기능은 그대로 동작합니다.

6. 외부 자원

화면 서체(Pretendard)는 jsDelivr CDN에서 불러옵니다. 이 과정에서 사용자의 브라우저가 해당 CDN 서버에 접속하며, 운영자는 그 접속 기록을 받지 않습니다. 결과 리포트의 출처 링크는 외부 사이트로 연결되며 각 사이트의 정책을 따릅니다.

7. 이 검사의 성격

이 검사는 DISC 4요인 모델의 구조를 참고해 문항·채점·해설을 자체 제작한 것으로, 어느 기업·기관의 공인 검사가 아닙니다. 결과를 채용·승진·평가 등 개인에게 불이익이 갈 수 있는 결정의 근거로 사용하지 마십시오.
